# SpeedUp Meta Tables

A WordPress plugin that answers slow postmeta and usermeta queries from narrow tables it builds and drops on its own, without changing how WordPress or any other plugin writes data.

Load the `speedup-meta-tables` skill (`.claude/skills/speedup-meta-tables/SKILL.md`) before any work in this folder: it holds the layout,
the decisions, the design rules and the release steps. The two files below are always loaded.
